# 🎯 초간단 시작 가이드

## Windows 사용자 (클릭만 하면 끝!)

### 1단계: 설치 (처음 한 번만)
```
"1_설치.bat" 파일을 더블클릭
```
→ 필요한 프로그램들이 자동으로 설치됩니다

### 2단계: 설정 (처음 한 번만)
```
"2_설정.bat" 파일을 더블클릭
```
→ API 키를 입력하는 화면이 나옵니다

**입력할 정보:**
- App Key: 키움증권에서 받은 앱키
- App Secret: 키움증권에서 받은 시크릿
- 계좌번호: 10자리 계좌번호
- 환경: **모의투자** 선택!

### 3단계: 실행
```
"3_실행.bat" 파일을 더블클릭
```
→ 프로그램이 실행됩니다!

---

## ⚡ 빠른 시작 (3분 완성)

1. 📥 **다운로드**: 프로젝트 폴더 다운로드
2. 💿 **설치**: `1_설치.bat` 더블클릭
3. ⚙️ **설정**: `2_설정.bat` 더블클릭 → API 키 입력
4. 🚀 **실행**: `3_실행.bat` 더블클릭

끝! 😊

## 🔧 명령 프롬프트 여는 법

### 방법 1: 가장 쉬운 방법!
1. 파일 탐색기에서 `stock` 폴더 열기
2. 상단 주소창 클릭
3. `cmd` 입력 후 엔터
4. 자동으로 해당 폴더에서 명령 프롬프트가 열림!

### 방법 2: 전통적인 방법
1. `Windows 키` + `R`
2. `cmd` 입력 후 엔터
3. `cd C:\경로\stock` 입력 (폴더 경로는 본인 것으로)

---

## 📍 설치 위치는 어디가 좋을까?

추천 경로:
```
C:\Users\사용자이름\Documents\stock
```

또는
```
C:\stock
```

**피해야 할 경로:**
- 바탕화면 (Desktop)
- OneDrive 동기화 폴더
- 한글이 포함된 경로

## ❓ 자주 묻는 질문

### Q: "1_설치.bat"을 더블클릭했는데 창이 바로 꺼져요
A: 정상입니다! 설치가 완료되면 자동으로 닫힙니다.
   오류가 있으면 창이 열린 채로 멈춥니다.

### Q: Python이 없다고 나와요
A: Python을 먼저 설치하세요
   https://www.python.org/downloads/
   설치 시 "Add Python to PATH" 꼭 체크!

### Q: API 키는 어디서 받나요?
A:
1. 키움증권 홈페이지
2. OpenAPI → REST API
3. 앱키 발급 신청
4. 승인 후 받음

### Q: 모의투자로 해야 하나요?
A: **네! 반드시!**
   실거래는 실제 돈이 들어갑니다.
   충분히 테스트한 후에만 실거래 사용!
